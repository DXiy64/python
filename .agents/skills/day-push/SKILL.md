# 学习文件提交与推送

读取AGENTS.md、TEACHING.md和本次用户指示，确认提交/推送授权及文件范围。2026-10-14持续授权涵盖“作业验收通过→生成并验证下一课→更新记录→提交推送本次学习文件”，无需重复确认；未通过、仅课程/技能审查均不触发。用户另行明确要求提交/推送时按该范围执行；当前指示优先。

先检查git status、工作区和暂存区差异以及分支/远程。只暂存已确认属于授权范围的文件；不使用git add -A夹带未知改动，不回滚学员改动，不自动推送其他仓库。若已有暂存内容不在范围内，保留并避免将其夹带提交。

README是摘要，LEARNING_PROGRESS记录能力证据，ROADMAP记录路线；改课时还核对[课程参考与知识覆盖表](../../../docs/curriculum/COURSE_REFERENCES.md)。未验收不标完成，历史结果与本次复测、帮助程度分开；百分比按完成单元计算。下一课目标TODO应保留，讲义与必要辅助模块/样本一起提交。

保留学员文本数据；.venv、work、运行数据库和生成报告按.gitignore排除。提交前查看暂存差异和实际文件清单，不能用生成文件存在代替验证。课程修改的验证与正在编辑的学员代码分别报告。

核实当前分支/远程后再提交和推送，不假定origin/main。分叉或冲突先检查原因，不强制推送、自动rebase或覆盖未知工作。提交后核对本次提交内容；若授权推送，读取远程分支SHA与本地提交比较，不能只凭“Everything up-to-date”或命令退出0宣称同步。超时先检查本地/远程状态，避免重复提交。

推送失败或权限不足时，说明本地已提交/尚未提交、远程是否已确认和阻塞原因，保留原文件；不把同步失败改写成作业未通过。本仓库教学技能在[python-project-tutor](../python-project-tutor/SKILL.md)，随本项目维护，不依赖全局技能目录，不自动写长期记忆或同步独立技能仓库。
